先建立一个正确的商业逻辑

01

采购的不是“公里”，而是运输资源与服务承诺

同样1,000公里，司机用车时间、空驶回程、货物可否堆叠、是否限行、是否要预约卸货，会让承运商投入完全不同。

02

同样价格单位，不代表同样成本边界

整车以车次报价，零担可能按吨、方或体积重计费；但装卸、过路、燃油、保价、空箱是否包含更决定可比性。

03

降本要改变成本驱动，再把效率收益写回价格

提高装载率减少车次、减少等待增加日周转、回程车减少空驶；如果合同不约定利益分配，运营改善不一定转化为采购降本。

01 / RFQ INPUTS + COST STRUCTURE

报价要素与成本定价机制：放在同一张逻辑图里理解

供应商需要的不只是起讫地和公里数。一个可靠的 RFQ 同时提供货物约束、每票货量、时效/运力服务边界，以及商务结算规则。这些字段共同决定承运商的成本和风险。

Cost driver tree

承运商“为什么报这个价格”？拆成四层成本

车辆与司机固定成本

折旧或租赁、司机工资、保险、管理与运力预留。

取决于：一趟占用多少时间、一天能跑几趟、空闲多少小时。
公里相关可变成本

油耗/电耗、轮胎、保养、通行费、停车、实际行驶里程。

取决于：实际路线 × 成本/公里 × 空驶与绕行。
服务、风险与利润

装卸、交付时效、额外站点、货损责任、调度系统、利润。

取决于：服务SLA、货物风险、合同边界及市场竞争。
成本建模的正确形式：单趟承运成本 ≈ 车辆与司机占用时间 × 时间成本 + 行驶公里 × 每公里变动成本 + 通行及操作附加 + 空驶/等待成本 + 风险与管理。报价还取决于供应商网络协同、竞争与利润目标，不能由成本唯一确定。

国内零担为什么要同时问重量与体积？以德邦公开规则为例

德邦官网的公开计费说明，精准卡航及精准汽运等零担产品按实际重量与体积重量两者较大值作为计费重量；公开标准轻泡系数例示为体积（cm³）÷ 4,800，签约客户则可按双方合同约定系数执行。另其帮助中心以约210 kg/m³解释轻重货区分。

这些是具体承运商对应产品的公开计费规则，不代表中国物流公司一律使用相同系数；整车业务又可能按每车/每线定价，不能把零担体积重公式套到整车。对招标最重要的是让每家公司明确提供单位、系数、最低收费与合同客户适用范围。

报价要素定义为何影响报价
RFQ 设计原则：报价信息的“完整”并不等于让客户准备所有SKU级数据。先用少量典型运输单元（标准箱/典型托盘）描述大多数货物，再对不可堆码、高值光学、特殊装卸等情形另列附表，以免报价工作量太高或误报。

同一线路，不同供应商为什么会差价？

1. “底层成本”不同

  • 回程货源：有返回订单的供应商可用相同车辆服务更多业务；无回程货可能把空驶成本摊入报价。
  • 线路网络密度：在某省/园区拥有密集客户的承运商，调车和接驳成本更低。
  • 车型与能源效率：车辆年限、油耗、电费、车厢规格、司机工资与用车效率不同。
  • 车辆与司机闲置：同一公里数但车次周转不同，固定成本差异大。

2. “报价口径和商业策略”不同

  • 服务边界：是否包含装卸、保险、托盘回收、GPS、夜间交付、等候。
  • 最低收费与体积重：零担可能因为换算系数与最低收费出现大幅差异。
  • 市场定位：供应商可能为了进入路线压低基价，也可能为特殊运力保障加价。
  • 燃油/旺季浮动：不同的附加费公式让静态报价难以直接比较。
APPLES-TO-APPLES / 同口径评标示例（非真实报价）
供应商 A：基础车价较低，但过路费、等候、空箱回收另计；供应商 B：基础价较高，但覆盖同等服务范围。不能只比较“基础车价”，应按统一运输情景比较全年总成本和合同执行条件。
这不是运费模拟器：不计算价格，只展示报价归一化要核对的费用项。
02 / TRANSPORT ARCHETYPES

运输方式与车型：先懂运力组织，再谈价格

“整车/零担”是承运组织与计费模型；“4.2米/9.6米/半挂”是车辆外形；“电车/油车”是能源类型。三者是不同维度，不应该混在同一层分类。

主干运输组织模式（示意图）

关键误区：整车不一定装满车；零担不一定更慢。真正的模式选择需同时考虑单票/平均发货量、线路密度、时效、货物兼容性与供应商服务网络。

车型大小与价格：车越大，运费一定越贵吗？

大车可能单趟总价更高，但在货量足够且可装得下时，每m³或每件的分摊运输成本反而更低。相反，车灯若体积大但很轻、箱体不可堆码，可能先占满车厢地板/容积，而不是达到车辆载重上限。

03 / PACKAGING + LOADABILITY

包装形式、车厢空间与堆码：为什么“方数”不等于可装数量？

包装不仅保护货物，还决定能否堆叠、是否需要托盘/叉车、回空占多少体积，最终决定一辆车能装多少可交付零件。图片为独立绘制的结构示意，非嘉利实物。

为什么有些货用纸箱、有些用胶箱？并非物流公司任意选择，而是由零件防护、尺寸重复性、交付频次、自动化/线边取用、回收闭环等共同决定。纸箱一次性材料费通常直观；胶箱/围板箱需要计入初始器具投入、回收、清洗、丢失和折返体积，不能只比购置价。

空间体积

货物“实际方数”来自外包装体积，但不能自动推算可用车厢装载率；不同箱型组合存在空隙。

地板面积

车灯制造业运什么？物流公司的特殊要求如何设定？

A / 强制门槛

安全与合规

道路运输资质、合规车辆、防雨防损、事故应急、货物交付和货损责任。符合规定才进入商业评标。

B / 货物特定

光学/电子专用

防刮、分隔、防静电、特定湿度或不可堆码，仅对验证有必要的物料写入合同与报价。

C / 可选增值

高标准服务

实时轨迹、专属司机、加急响应、24/7值守，按可选服务单独报价而非默认全线标配。

质量检验与供应商能力检查清单（招标前）

01样件与包装验证

堆码/震动/跌落或实际运输试验记录；以客户批准的防护边界为准。

02装卸与车辆条件

是否全程厢式、干净干燥、地板固定点、是否有合适叉车及尾板。

03批次与异常追溯

按箱/托盘标签、装车照片、电子签收、破损留痕与索赔时限。

04供应保障与应急

车辆调度覆盖、节假日、停线紧急件、故障替代车辆与通知时限。

采购判断：物流供应商可在报价环节获得“运输约束”，不必获得商业敏感的完整零件图纸；但涉及不可叠压、ESD、光学洁净等限制时，要由包装工程/质量团队确认具体工艺标准，不能由采购自行假设。
05 / PROCUREMENT EXECUTION

物流招标实操：从 RFQ 到中标，如何避免“价格最低却成本最高”

真正完整的物流招标不只是把线路表发给几家物流公司，而是先确定服务规格与标包，再收集多方案报价、归一化成本、评估承运风险，最后把改善写入合同和实际派单规则。

一套可复制的 8 步物流招标路径

01

需求与历史账单整理

线路、货量P50/P90、时效、实际车次、装卸和全部费用边界。

02

RFI资格预审

承运资质、区域覆盖、车队、分包管理、保险、应急保障。

03

标包/中标规则设计

逐线、区域、往返组合；允许单线和组合折扣同报。

04

RFQ标准化发布

报价单位、燃油规则、附加费、最低收费、服务SLA、合同草案。

05

澄清与首轮报价

解释特殊包装、交付窗口和计价口径；禁止不透明排除项。

06

同口径比价+反馈

逐线路红黄绿评价、服务非价格项打分、邀请改善方案。

07

二次报价与定标

评估主供/备供组合，容量风险与切换成本，签署价格表。

08

派单与绩效落地

按中标路线分量、核对逐票账单、月度服务记分卡与纠偏。

标包怎么划分？四种方案不是互斥，关键是“主包 + 可选组合报价”

MODEL A / LANE-BASED

逐线路标包

示例：温州 → 苏州、温州 → 宁波独立报价。
适用：同一线路运量足够、供应商优势强差异明显。
好处：透明、可逐线选择最低可行价格。
弱点：忽略多个线路共享车辆或回程网络的折扣。

基础报价必须保留
MODEL B / REGIONAL

区域/流向标包

示例：华东地区若干常规线路或同方向线路作为区域包。
适用：供应商本地覆盖能力强、线路可共享车队。
好处：提高规模与网络密度。
弱点：弱势区域可能把组合价抬高，需逐线拆分。

适合做组合折扣
MODEL C / MODE-SERVICE

车型/服务等级标包

示例：固定班车、零担、特殊光学器具运输分开。
适用：时效、包装、装卸差异明显。
好处：避免把不同成本结构的服务强行混比。
弱点：车型过细会碎片化供应商竞争。

先定义共通服务规格
MODEL D / NETWORK PAIR

往返配对与跨基地组合包

示例：长距离去回方向配对、多个近邻厂区合并调度。
适用：有可匹配的返程货或循环器具流向。
好处：可能降低空驶/调车成本。
弱点：时窗冲突、货权责任与运营协调更复杂。

要求供应商主动建议
推荐的RFQ结构：所有线路必须先按统一口径逐线报价；再开放承运商对区域包、去返组合包提交有条件的额外折扣。这样可以同时实现可比性与网络优化，不会只得到一个无法拆解的“总包价”。

一张真正能让供应商报价的 RFQ，至少要包含哪些 Sheet？

工作表采购提供承运商填写关键校验
01 线路/服务需求始发/目的地、单票典型量、车型候选、SLA、月度车次与波动可服务、推荐车型与线路说明路线与计时节点一致
02 基础价表统一线路编码、含税口径、车型/零担计价单位各线路整车价、零担阶梯价与最低收费不得仅填“另议”

06 合同偏离表标准合同、约定附加费项目、质量索赔条款逐项接受/偏离、理由和潜在额外费用所有偏离项可转化为同口径成本/风险

评标不只是排名：先“资格门槛”，再“归一化成本”，最后“承运组合”

I

门槛筛选

运输资质、保险、运力覆盖、可追溯、货损和紧急处理。不可用低价来替代不合格服务。

II

报价归一化

把税、燃油、路线、零担体积重、最低收费及所有附加费用放在同一个情景里。

III

中标组合

逐线最低可行价之外，还评估容量承诺、备用供应商、组合折扣和执行切换成本。

06 / FULL VALUE LEVER LIBRARY

物流年度降本抓手库：每一个抓手改变了哪项成本？

借鉴两份 KN，按「商务议价 / 运输运营 / 运输网络 / 合同与执行」组织 21 个可落地抓手。展开任何一项，查看作用机理、执行动作、实施前提、风险与可以直接问物流公司的问题。

节约口径：合同单价降幅、车次减少、返空成本下降、异常费用追回与营运现金流改善是不同的收益类型，不应直接加总。每条措施必须明确基线、归属、实施开始月份、抵销成本与SLA变化后才可记入年度降本。

抓手优先顺序不是“百分比越大越好”，而是执行障碍越低越先做

落地波次建议优先动作所需信息谁拥有决策权
Wave 1 / 谈判准备逐线比价、附加费表、账单审计、燃油机制、标准RFQ现有合同、线路历史票据、实际附加费及供应商绩效采购主导；财务验证
Wave 2 / 采购再设计集中标包、第二轮招标、备用承运、零担整车阈值单票货量、供应商可达性、线路图谱、业务承诺采购 + 物流运营
Wave 3 / 运营协同发运频次、等候错峰、标准箱、堆码、回程车、多点配送包装验证、客户时窗、装卸时间戳和周转器具资产物流运营 + 包装/质量 + 客户服务
Wave 4 / 网络重构仓网/直发方案、专属运力与替代能源、跨基地深度整合全链路成本、需求预测、跨部门和供应商协同供应链负责人 / 跨部门治理

分波是本报告的执行建议，并非 KN 中的固定顺序。KN 2023 按机会优先级、合同周期、团队协同和实施难度安排执行。

07 / EVIDENCE + LIMITATIONS

KN 案例：有哪些经过项目验证的机制？不能误用哪些数字？

下列均出自你提供的两份 KN。为了可审计，展示案例原始语境、可借鉴的推理及中国汽车零部件场景的适用边界；没有将历史案例节约率当作嘉利可实现比例。

8–15%跨品类历史案例区间

BCG历史运输与物流品类可寻址支出的平均节约范围

2023 Playbook 指出，历史项目中运用综合采购抓手后，重点运输及物流品类的可寻址支出平均产生 8–15% 节约，明确排除市场价格本身变化。

启示：效果来自价格、需求、合同和流程的组合，而非单纯压价。

边界：不是嘉利目标或预测，也不是中国公路货运专属均值。

40/73高于最低参考价的线路

逐线路比价比“整包平均价”更有价值

一项案例对73条线路逐线比对，发现40条成本高于相应最低市场参考；针对这些路线谈判，示例总干线成本不含燃油费可降低约6%。

启示：即使供应商整体价格表现良好，也可找到单线异常；应在招标后进行红黄绿逐线反馈。

边界：美国地区2019–2020年数据，不代表中国线路运价差距。

20%该项目中部分空驶公里

回程货源可能比单价谈判更重要

2023 KN 一个干线案例显示存在约20%的空驶公里；2012 KN 的机制示意指出，设计回程货可将载货里程占比从50%提高至75%（仅概念例子）。

启示：招标允许供应商设计回程货、往返配对及空箱回收方案，并将降本明确写入报价。

边界：20%来自单一案例；50%→75%为示意，不应作为目标或基准。

LTL→FTL存在模式切换分界

按单次货量和服务条件决定零担还是整车

2023 Playbook 的一个线路分析以整车价格水平与零担货重成本比较，揭示部分实际运输单据被错分到较贵模式。模型中分界货重已匿名化。

启示：采购应在 RFQ 中获取同线两种模式的报价与最低收费，并把调度规则写入执行。

边界：分界重量受时效、密度、包装与实际价阶影响，没有可通用的“多少方一律整车”。

费用拆分管理费中可能藏高成本

低运输基础价不等于低总物流价

2023 KN 另一个网络方案比较案例发现，承运商将较多成本放在管理费内，使表面干线价格显得有竞争力。

启示：RFQ 要求运输、管理、能源、附加费和其他服务独立报价，按同一成本边界评标。

边界：不能凭此推定任何特定供应商存在不当收费；必须基于发票与合同核实。

2/3该示意中订单集中早上

错峰交付不是简单推迟，而是减少高峰配置

2012 KN 使用早间需求占三分之二的示意说明：高峰决定要配置多少合同车辆，下午却可能闲置。扩大可交货窗口有机会改善固定成本利用。

启示：采购与客户运营联合谈车次/时窗，承运商因此可减少固定车辆和相关报价。

边界：此图为说明机制的示例，不是嘉利需求结构。

可借鉴 vs 不可直接套用

可迁移的方法

  • 按逐票数据建立线路 × 服务层级 × 车型的报价基线。
  • 固定成本和公里相关成本分开，识别等待与空驶。
  • 以同口径 RFQ、多轮投标和承运商组合进行定标。
  • 要求承运商主动提交网络优化、返程、专属运力方案。
  • 从账单与KPI验证已谈妥的节约真正落地。

不可直接套用的数字/条件

  • 海外运价（$/mile、€/ton）、油价/司机工资与费用构成百分比。
  • 案例的8–15%、20%空驶或特定线路6%节约，作为嘉利目标。
  • 美国合同/专车网络选择的公里/发运频率阈值。
  • 国外车型载重或包装条件替代中国车辆证照和客户工程规范。
  • 将“可回程/可堆码”写成承运商保证，未通过验证就降价。
